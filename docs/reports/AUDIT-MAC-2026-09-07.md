## 2. MASALAH KRITIS

### 2.1 Disk Hampir Penuh — 88%
**Bukti:**
```
Filesystem          Size   Used   Avail  Cap
/dev/disk1s1        128Gi  92Gi   13Gi   88%   /System/Volumes/Data
/dev/disk1s4s1      128Gi  16Gi   13Gi   55%   /
```
Hanya **13GB tersisa** di volume Data. Ini mendekati batas kritis — macOS mulai throttle performance jika di bawah 10GB. Hermes `state.db` 159MB, log gateway 7.5MB, `models_dev_cache.json` 4.3MB semuanya terus tumbuh.

**Kontributor terbesar yang diidentifikasi:**
| Path | Ukuran | Keterangan |
|------|--------|------------|
| `archive/sapa-ai.bak` | 892MB | Backup lama |
| `archive/projects` | 647MB | Arsip proyek |
| `archive/backup` | 293MB | Backup tambahan |
| `niu-mission-control` | 506MB | Termasuk node_modules 487MB |
| `Movies/*.mp4` | >500MB × 3 | Video tutorial AI Creator Labs |
| `Downloads/[ANICHIN...].mkv` | >500MB | File anime |

**Total yang berpotensi dibebaskan tanpa risiko: >3GB** (archive + media yang tidak terpakai)

**Tindakan yang disarankan (segera):**
1. Hapus/pindah 3 file video di `~/Movies/` ke external drive atau hapus jika tidak diperlukan lagi
2. Hapus file MKV di `~/Downloads/` (>500MB)
3. Hapus `archive/sapa-ai.bak` setelah verifikasi
4. `npm prune` di `niu-mission-control/apex-ui` → potensial hemat ~100MB

### 2.2 Tidak Ada Time Machine Backup
**Bukti:**
```
tmutil latestbackup → (kosong, tidak ada output)
```
Tidak ada backup terbaru yang terdeteksi. Dengan disk yang hampir penuh dan 7 commit `niu-cast` yang belum push, ini risiko kehilangan data nyata jika terjadi kegagalan hardware.

**Tindakan yang disarankan:** Hubungkan ke external drive dan jalankan backup Time Machine segera, atau verifikasi apakah backup dikonfigurasi ke cloud/NAS yang tidak terbaca oleh `tmutil`.
