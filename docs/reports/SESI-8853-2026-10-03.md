## 3. Pemeriksaan Kebutuhan Jalur + Pemasangan LibreOffice

**Kondisi toolchain sebelum:** pandoc 3.11 ✅, python-docx ✅, qpdf 12.4.1 ✅,
LibreOffice **❌ tidak ada**.

**Mengapa LibreOffice wajib:** `build-dokumen.py` memakai rute
`md → pandoc → DOCX → soffice → PDF`. Pandoc tidak bisa produksi PDF tanpa
engine LaTeX terpisah. Tanpa `soffice`, Jalur A selalu keluar **kode 2**
(DOCX dibuat, PDF tidak) — artinya **tidak pernah ada surat dinas siap kirim**.

**Dikerjakan:**
1. `brew install --cask libreoffice` → LibreOffice 26.8.0.3
2. `soffice` ditambahkan ke PATH permanen (`~/.zshrc`, repo `dotfiles`)
3. Uji end-to-end `templates/SURAT-DINAS.md` → **RC=0** (DOCX + PDF + meta.json)

### Bukti

```
$ python3 scripts/build-dokumen.py templates/SURAT-DINAS.md
✅ templates/SURAT-DINAS.docx memenuhi Ps. 28 / 32 ayat (2) / 34 ayat (2)
   font Arial 12.0 pt · kertas F4/Folio (21,5 x 33,0 cm)
   ruang tepi {'top': 2.0, 'bottom': 2.5, 'left': 3.0, 'right': 2.0}
OK templates/SURAT-DINAS.pdf

$ bash scripts/uji-gate.sh
SKENARIO: 16   PEMERIKSAAN: 18 lulus, 0 gagal

$ python3 scripts/secret-scan.py .
✅ tidak ada temuan
```

**Catatan:** build uji + `meta.json` dihapus dari `templates/` karena artifact,
bukan template. `templates/meta.json` belum masuk `.gitignore` — setiap build
akan menimpanya; usul ditambahkan ke `.gitignore`.

## 4. Temuan Platform — Homebrew Tier 3 ( Intel x86_64 )

Homebrew mengeluarkan peringatan saat pemasangan:

> *We do not provide support for this platform (as-of September 2026, announced
> August 2025). Apple have dropped Intel x86_64 support in macOS Golden Gate
> (27). GitHub Actions are dropping macOS Intel x86_64 runners in 2027.
> Homebrew no longer builds bottles for this configuration. Existing bottles
> may still work, but updated formulae may build from source.*

**Konsekuensi:** `brew upgrade` pada formula populer mungkin build dari source
(lebih lama, bisa gagal). Bottle lama tetap valid — paket yang sudah terpasang
tidak akan hilang. Catatan penuh + inventaris toolchain dicatat di
`docs/registry/deployment-status.md` seksi "Host & Toolchain".
