## Masalah Build

**HP Infinix X6873 sudah terhubung** tapi app tidak bisa di-build karena **NDK corrupt**.

File NDK yang diunduh (`android-ndk-r26b-darwin.zip`, 939MB) extraknya tidak lengkap:
- Tidak ada `sysroot/` directory
- Tidak ada `lib/clang/*/lib/linux/*.a`  
- Compiler clang ada tapi linker tidak bisa find crtbegin_dynamic.o

**Penyebab:** Download mungkin terputus atau mirror Google membatasi kecepatan.

---

## Solusi (Pilih Salah Satu)

### Opsi 1: Install Android Studio (Paling Mudah)
```bash
brew install --cask android-studio
# Buka Android Studio → SDK Manager → Install NDK
# Setelah terinstall, set PATH:
export ANDROID_NDK_HOME=$HOME/Library/Android/sdk/ndk/26.1.10909125
```

### Opsi 2: Download Ulang NDK Dengan wget
```bash
wget "https://dl.google.com/android/repository/android-ndk-r26b-darwin.zip" -O /tmp/ndk.zip
unzip /tmp/ndk.zip -d /usr/local/Caskroom/android-platform-tools/37.0.1/
cd /usr/local/Caskroom/android-platform-tools/37.0.1
rm -rf ndk/27.0.12077973
ln -sfn android-ndk-r26b ndk/27.0.12077973
```

### Opsi 3: Pakai Build Machine Lain
Jika macOS memiliki masalah jaringan, bisa build di VPS/Linux dengan:
```bash
apt-get install openjdk-21-jdk flutter
git clone ...
flutter run
```
