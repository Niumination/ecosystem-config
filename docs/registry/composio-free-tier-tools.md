## Catatan pemakaian

- **Yang belum diverifikasi jangan dijanjikan** ke pengguna/klien: sebutkan tanggal sumber (18 Agu 2026) saat mengutip angka.
- **Buffer vs Pallyy** sama-sama untuk penjadwalan IG; Buffer lebih luas platform, Pallyy lebih longgar untuk akun tunggal.
- **Postiz self-hosted** satu-satunya opsi tanpa batas — tapi menuntut VM (jangan di laptop 16 GB; lihat larangan resource di `docs/references/`).
- **Composio (Kelas B)** punya free tier sendiri; lihat `composio-integration-plan.md` untuk jalur MCP/API.
