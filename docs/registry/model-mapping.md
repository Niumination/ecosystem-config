## Auto-Discovery Procedure

1. **Enumerate models**
   ```bash
   python3 scripts/model-checker.py --list
   ```
   atau via HTTP:
   ```bash
   curl -s -H "Authorization: Bearer $NINE_ROUTER_API_KEY" \
     http://127.0.0.1:20128/v1/models | jq -r '.data[].id'
   ```

2. **Verify accessibility**
   ```bash
   python3 scripts/model-checker.py --test <model_id>
   ```
   - Probes `/v1/chat/completions` with a minimal request.
   - Classifies as `gratis` / `berbayar` based on provider metadata.
   - Retries on transient failure; marks `UNREACHABLE` after 3 misses.

3. **Record fallback chain**
   - Every mapping must have at least one **HTTP-200 verified** fallback.
   - Primary = explicit proven model used for the target thread/DM.
   - Fallback = secondary model triggered on provider error/timeout.

4. **Persist mapping**
   - Results are stored in `scripts/model-checker-report.md` and `scripts/model-checker-data.json`.
   - This file is regenerated by the checker; do not edit manually.
