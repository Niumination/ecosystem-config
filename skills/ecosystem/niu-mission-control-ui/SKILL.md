### Struktur unified index.html (generated by build_unified.py)
```
build_unified.py → index.html (single file, ~83KB)
├── <head> — meta (SEO: description, robots, OG, theme-color), fonts, styles.css
├── <h1 class="visually-hidden"> — screen-reader only (WCAG heading hierarchy)
├── .orb-base > iframe[orb.html] — fullscreen 3D background
├── .orb-dim[aria-hidden] — overlay saat window aktif
├── nav.launcher[role=toolbar] — 12 launch-btn (aria-pressed)
├── main#winMount[role=dialog target] — floating windows mount
├── div#pageVault[aria-hidden] — 12 page sections (hidden, dipindah ke window saat buka)
├── div.taskbar[role=toolbar] — 12 tb-btn (role=button, tabindex=0) + clock + ORB LIVE
└── <script> — window manager (openWindow/closeWindow/focusWindow + cascadePos + keyboard)
```

### Floating window system (inline di build_unified.py, bukan app.js)
- `openWindow(appId)` — buat `.fwin[role=dialog][aria-label]`, pindah section dari vault
- `closeWindow(appId)` — animasi `.closing` 240ms, pindah section balik ke vault
- `focusWindow(appId)` — z-index stacking, class `.focused`
- `cascadePos()` — offset 52/42px berantai, wrap ke (20,20) jika keluar viewport
- Keyboard: Escape close, Enter/Space taskbar toggle, fokus pindah ke window saat buka via keyboard

### File files
- `dashboard/build_unified.py` — generator HTML (template f-string, pages_js + sections)
- `dashboard/app.js` — business logic (agent cards, kanban, telemetry, WS handlers)
- `dashboard/styles.css` — dark glassmorphism theme (WCAG 2.1 AA compliant)
- `dashboard/orb.html` + `orb.js` — ORB 3D canvas
